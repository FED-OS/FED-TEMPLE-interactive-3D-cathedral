If FED-TEMPLE contributed to your work — a blog post, a talk, a paper, a portfolio piece, a viral tweet — we'd be honored if you cited it. Suggested formats below.

  author       = {{FED-OS}},
  title        = {FED-TEMPLE: The Digital Monument},
  year         = {2026},
  version      = {0.1.0},

  note         = {Browser-native 3D visualization of GitHub contribution history}
}

## ✦ Related work

If you're writing academically about contribution visualization, you may also want to cite:

- Three.js (Ricardo Cabello et al.) — the rendering foundation.
- GitHub's public REST API — the data source.
- Prior art in contribution visualization: GitHub's contribution graph, isometric.city, github-contributions-3D, and the broader "code as art" tradition.

We don't claim novelty over the *idea* of visualizing commits — only over this specific brutalist, browser-native, no-backend implementation.
