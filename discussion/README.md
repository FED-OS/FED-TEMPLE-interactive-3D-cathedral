# Discussion — FED-TEMPLE

> This folder archives notable community discussions and decision threads so they survive beyond GitHub's transient Discussion timeline. For live conversation, use [GitHub Discussions](https://github.com/FED-OS/FED-TEMPLE/discussions). For the discussion welcome guide, see [.github/DISCUSSION_WELCOME_README.md](../.github/DISCUSSION_WELCOME_README.md).

## ✦ How to use this folder

When a Discussion concludes with a decision that should be durable (a roadmap addition, an ethos clarification, a rejected proposal with valuable reasoning), summarize it here as a dated file and link it from the relevant doc (ROADMAP.md, ADR.md, etc.).

Filename format: `YYYY-MM-DD-short-slug.md`.
