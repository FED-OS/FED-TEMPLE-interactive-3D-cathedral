## ✦ How to get on this list

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Open an issue or discussion for anything beyond a typo/bug.
3. Send a PR that fits the ethos.
4. When it merges, add yourself to the Contributors section above (alphabetical within each cohort, or chronological — keep it consistent).
