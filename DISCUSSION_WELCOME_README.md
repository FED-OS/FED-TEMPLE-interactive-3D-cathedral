# 👋 Welcome to FED-TEMPLE Discussions

This is the home for **FED-TEMPLE** community conversation — questions, ideas, show-and-tell, and roadmap input. Issues are for bugs and concrete feature requests; Discussions are for everything else.

## ✦ Before you post

- Read the [README](https://github.com/FED-OS/FED-TEMPLE#readme) — especially the **Rate limits** and **Features** sections.
- Skim the [FAQ](https://github.com/FED-OS/FED-TEMPLE/blob/main/FAQ.md).
- Search existing discussions to avoid duplicates.

## ✦ Categories

| Category | Use it for |
|----------|-----------|
| **📢 Announcements** | Maintainer posts — releases, roadmap shifts, calls for help. (Read-mostly.) |
| **💡 Ideas** | Feature proposals, "what if the temple did X," wild experiments. |
| **❓ Q&A** | "How do I…?" questions that aren't bugs. |
| **🏗 Show and tell** | Post your temple! Share screenshots, standalone HTML, time-lapses. Flex freely. |
| **🗺 Roadmap feedback** | Comment on [ROADMAP.md](https://github.com/FED-OS/FED-TEMPLE/blob/main/ROADMAP.md) items. Upvote with 👍. |

## ✦ House rules

1. **Be kind.** Read the [Code of Conduct](https://github.com/FED-OS/FED-TEMPLE/blob/main/CODE_OF_CONDUCT.md). It applies here too.
2. **Stay on ethos.** Proposals that require a backend, required auth, telemetry, or a build step will be gently redirected — see [ADR-0001](https://github.com/FED-OS/FED-TEMPLE/blob/main/ADR.md). Don't take it personally; it's the constitution.
3. **No spam / self-promo unrelated to the project.** A link to your temple is welcome. A link to your crypto course is not.
4. **One idea per thread** so upvotes and answers stay coherent.

## ✦ Getting help fast

- Bug → [open an Issue](https://github.com/FED-OS/FED-TEMPLE/issues/new/choose) with the bug template.
- Security problem → email the address in [SECURITY.md](https://github.com/FED-OS/FED-TEMPLE/blob/main/SECURITY.md). **Do not post security issues publicly.**
- "How do I use X?" → Q&A category here.

## ✦ Want to contribute code?

Read [CONTRIBUTING.md](https://github.com/FED-OS/FED-TEMPLE/blob/main/CONTRIBUTING.md) and [CLAUDE.md](https://github.com/FED-OS/FED-TEMPLE/blob/main/CLAUDE.md). Start with a "good first issue" label.
